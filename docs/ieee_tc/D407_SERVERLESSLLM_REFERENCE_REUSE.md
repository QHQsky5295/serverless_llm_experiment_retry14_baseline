# D407 — ServerlessLLM 7B：复用独立数值参考，返回负载验证

日期：2026-10-11。未新增 GPU 实验、权重、负载或远端缓存。

## 决定

沿用冻结 V1 与 D393 已澄清的同一标准：请求、原生 adapter 身份、内容来源、
目标输出数和终态计量须完整；不同后端不强求逐 token 相同。不重新引入 D391
已经被 D393 纠正的“4,000 条跨后端逐 token 相同才可比较”要求，也不把
HTTP 200 或输出数量单独当作 adapter 正确性。D406 的原始未知数值字段不改写。

D404 的原生输出可以直接与 D385 已完成的独立 HF/PEFT 参考关联，无须重复
100 请求 GPU 检查。D407 重新核对 D404 的原生计量、交付、内容和物理生命周期，
再逐请求核对 D385/D384 的源 SHA、请求、adapter、prompt-token hash、目标数量、
完整输出序列 SHA 和原始 adapter 文件。所有 100 条输入身份一致。

| 权重类别 | 请求数 | 与独立参考完全相同 |
|---|---:|---:|
| finance_lora 非零 A/B | 24 | 22 |
| medical_lora 非零 A/B | 13 | 12 |
| rank-8 零 A/B | 47 | 44 |
| rank-16 零 A/B | 16 | 16 |
| 合计 | 100 | 94 |

六条差异全部保留：req_00018、00022、00046、00059、00084、00094。
其中三条的首差异位置及原生 token 与 D385 的独立观测完全相同，可复用其
top-2 间距 0 或 0.015625；另外三条没有对应位置的独立 logits，保持未知，
不笼统宣称六条都是舍入误差。不另设宽容阈值或删除差异请求。

这提供四类现有权重的有界数值一致性证据，不证明每个 kernel 的算术正确性、
500 个独立训练任务或完整工作负载语义质量。全部 500 个逻辑 adapter 的实际
执行和远端内容覆盖由 D406 单独提供。两种证据不能互相冒充。

## 官方实现与适用边界

核对本机 ServerlessLLM vLLM 0.10.2 接口后，实际请求将已核验路径传入
LoRARequest，原生 V1 request state 回传 name/int-ID；文件交付 SHA 与原生
请求身份联合验收。不是仅按目录名称推测加载成功。

[vLLM 0.10.2 LoRA 文档](https://docs.vllm.ai/en/v0.10.2/features/lora.html)
定义 name、全局整数 ID 和路径接口；
[相同版本复现性说明](https://docs.vllm.ai/en/v0.10.2/usage/reproducibility.html)
限定其复现条件，在线调度不保证复现。这是保留不同后端输出差异的背景，
不是证明任意输出正确的依据。不改变当前运行方式以筛选匹配结果。
