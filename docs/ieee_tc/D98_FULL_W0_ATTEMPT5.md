   先成功持有 `code_lora` HOST 来源，随后 `code_lora_0039` 的回执明确为

   引用正常释放，计划关闭成功，无清理或计量错误。`stale_snapshot` 证明版本
   检查拒绝，不证明工件内容实际改变或 owner 变更；更具体的并发原因待测试。
2. D98 的 CPU 对照证明减少无关引用变化造成的拒绝，但本次提前结束，不能
   据此宣布 Full 延迟、SLO 或吞吐优于上一版本。成功子集与旧整轮不能直接比较。
3. 原始错误、计划事件、请求、51 对 UUID、资源释放及 147 个保护条目已核验；
