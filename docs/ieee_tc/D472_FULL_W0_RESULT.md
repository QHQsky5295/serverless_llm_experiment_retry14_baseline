本轮 4,000 请求的原生生成数量、源请求、adapter 内容与执行绑定合同全部通过；
共同联合 SLO 为 3,807/4,000，超过固定门槛 3,800 **7 个请求**。
TTFT 达标 3,840，TPOT 达标 3,955；仅 TTFT 违约 148，仅 TPOT 违约 33，
同时违约 12。原始独立数值正确性字段仍为未知，不能把绑定审计冒称核函数数值证明。

总物理占用 10,904.660678 GPU-s。在共同 SLO 可行的观测点之间，本轮相对：

- PrimeLoRA D371：资源减少 24.7047%，联合 SLO 低 2.525 个百分点；
- PrimeLoRA D458：资源减少 8.9483%，联合 SLO 低 1.275 个百分点，P95 TTFT 高 15.3694%；
- ServerlessLLM：资源减少 32.2261%，但联合 SLO 低 2.95 个百分点，尾延迟更高；
- vLLM：资源减少 32.3338%，但联合 SLO 低 4.30 个百分点，尾延迟更高；
- ElasticLocality：资源仍高 10.2292%，联合 SLO 低 0.60 个百分点，P95 TTFT 高 35.7103%。

相对 D465，资源减少 9.0076%，联合 SLO 提升 0.425 个百分点，P95 TTFT
降低 6.6731%；D465 的非可行身份保留，不能把它当达标资源排名的竞争点。

**接受 D472 为新的、W0 达标且比既有达标 PrimeLoRA 更省资源的开发检查点；
不宣布系统最优或完整 G1/G2 完成。** 这是预定单轮的结果，不通过重跑筛选。
CPU 准备路径具备真实生命周期证据；闭环性能差异不能解释为逐次启动节省的简单总和。
D463 仍是父版本中的语义保持修改，其独立性能收益未获支持；本轮不替其补造归因。

## 2. GPU 生命周期与 CPU 准备机制

互斥时间窗：业务前 35.725034、到达窗口内 10,742.815039、drain 3.244638、
终态后清理 122.875967 GPU-s，之和与总物理占用一致。W0 预算比例
为 0.902216（预算 12,086.532872 GPU-s）。W0 合规不替代 W1/W2 的 G2 验证。

18 个固定 GPU UUID 的 CPU 准备进程全部有真实出生、准备观察、激活许可、
实际物理租约、原生 worker 退出和归还记录，退出码均为零。其中初始准备 4 个，
同卡归还后新建准备 14 个；每次前一物理归还早于下一准备进程出生，物理区间不重叠。
本轮无未使用准备进程。18 次许可不等于 18 个 engine-ready：初始激活 1 次 ready，
自然扩容触发 17 次，其中 14 次 ready、3 次未 ready，全部保留。

CPU 准备约 10.87–12.96 秒；记录中 torch CUDA 未初始化、当前 context 为零、
primary context 未激活。各进程在许可前有 13–2,398 次本机原生 census，
相应 GPU 未出现本服务持有的 context。离散采样不能排除所有瞬态。
初始卡实际 acquire 比 CPU 准备完成早约 0.550 秒，此段已计费，未后移分配时钟。
CPU 准备占共同服务 CPU/内存，不使用未来请求，不把持卡 sleep 当免费资源。

本轮平均 TTFT 1,303.724 ms，其中 dispatch/admission 等待 680.079 ms、
service TTFT 623.645 ms；平均 TPOT 33.809645 ms、P95 TPOT 57.176180 ms，
平均 E2E 5,105.544 ms。加和分解用于定位，不能独自证明因果关系。

## 3. 输入、远端、正确性与安全边界

- 独立 D435 输入见证逐请求一致；合同 SHA
  `384b63425402ced97961e91081265d3cbe340b6a3b4febde242de28f62cd7399`。
- 458,224 原生输出 token；遇到 132 个逻辑 adapter。原池 500 个逻辑 ID、
  498 个零权重／2 个非零、4 个权重 SHA／6 个目录内容类的限制不变。
- 同后端输出 digest 相对 D371、D453、D458、D465 分别有 196、195、205、175
  条变化，全部保留；不未经验证归因为舍入、批次，也不推断错误 adapter。
- 132 次真实远端传输，131,480,060 线上字节，两端一致且全部关联请求；
  复用 D78/D80 只读 gzip，请求中打包为零。相对相同 132 次获取的对照，
  此 W0 没有隔离证明减少远端传输的优势。
- 实验前链路 1 Gbit/s/full；必要读取、传输、竞争和本地物化仍计入时延。
- 4,061 个资源样本；服务内存峰值 21,431,332,864 字节，high/max/OOM/
  oom_kill/swap 均为零；原生时间重建通过。无此类事件不证明无全部环境扰动。
  watchdog 无告警；systemd 另有两条 inotify 告警，保留且不假定性能影响为零。
- 实际 GPU 释放、服务路径移除后才停止本轮远端服务；所有辅助任务以实际
  递归成员为空及捕获的进程域身份核验收尾。原 Kubernetes 集群未改动。
- 原完成回执继承的 `native100` 文本不修改；单独 annotation 标明本次 4000，
  原始测量、SHA 和完整失败历史均保留。
