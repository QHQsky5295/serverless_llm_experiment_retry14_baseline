正确性。四个物理持卡区间均已释放，诊断占用 4,452.071693 GPU-s。服务、
回放、监控均退出为 0，实际进程与资源域消失后才停止三个本次远端服务。

1,474,429,899；全部 published，无请求内打包、无字节不一致。
