在这些已测 W0 点中，满足共同联合要求的 PrimeLoRA、vLLM 和 ServerlessLLM

0.625 个百分点，相对 ServerlessLLM 高 0.725 个百分点。因此本轮支持
“满足共同服务要求时减少 GPU 占用”，不支持“所有原始延迟都第一”。
HydraServe 的资源更低，但未满足共同联合要求；不删除或隐藏这个点。

旧源码 W0 D989 的联合达成为 99.025%，比本轮高 0.175 个百分点；保留旧
观察，不据本轮成功宣称它在所有指标上胜过旧实现。新版本必须与 D1100 W2
及尚待执行的 D1115 W1 形成同源码、同配置的完整三场景观察。
