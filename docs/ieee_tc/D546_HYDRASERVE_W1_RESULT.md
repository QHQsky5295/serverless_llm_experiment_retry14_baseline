- 4,000/4,000 请求完成原生绑定及固定输出合同检查，458,224 个原生输出 token，
  132 个实际请求 adapter ID，无失败。独立数值 LoRA 正确性仍未知，原始
  `n_correct=null` 不改写；500 逻辑 ID 仍为原有 498 零权重／2 非零的集合。
- 与 D536 的全部 4,000 请求逐项核对 request、adapter/content/manifest、prompt、
  原生输入 ID hash、source-item、target 和相对计划到达；并连接 D533/D537/
  D542/D544 已封存见证。输入一致不代表后端版本、缓存历史或部署方式一致。
- 复用 D510 的原生修改版 vLLM 0.4.2、调度与 idle retirement；21 个实际 worker
  均为 pp1、batch8。没有本轮 pipeline/consolidation 效果证据，不将未触发机制
  归因为收益或缺陷。既有 k3s 未访问或改动，继续采用隔离 rootless Podman。
- 132 次真实远端获取，131,480,060 线上字节；双端关联及内容核对通过，零请求内
  打包。采用启动前核实的 1 Gbit/s 链路，不删除真实传输和本地物化时延。
- 服务、回放与监控均正常退出，全部 GPU 实际释放；远端三个自有服务已关闭。
  服务峰值 53,797,986,304 B；high/max/OOM/kill/swap 均为零。
