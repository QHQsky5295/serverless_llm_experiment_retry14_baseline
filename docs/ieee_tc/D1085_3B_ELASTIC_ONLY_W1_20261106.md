# D1085：3B ElasticOnly W1 同版本 A1 更新登记

## 目的与唯一改变

D1085 更新既有 3B `ElasticOnly` W1 消融，使其与 D1082 Full W1、D1083 Full W0
和 D1084 Full W2 使用同一份当前 PrimeLoRA serving implementation。它不是
重新调参，也不是外部 baseline；唯一系统语义仍是 A1 已冻结的 ElasticOnly：
保留 autoscaling、vLLM backend、物理 allocation、请求驱动缓存和普通
load-only routing，关闭主动 adapter management、hierarchical residency、
handoff 和 effective-capacity admission。

D1085 的作用是为 D1082 Full W1 提供同版本机制对照，直接检验 elasticity-only
是否已经解释当前资源/尾延迟结果。若 Full 与 ElasticOnly 的差异不足或方向相反，
如实记录 trade-off；不通过改变 ElasticOnly 的定义、注入等待或削弱其缓存来
制造优势。D1057 的旧版本结果保持原身份，不被覆盖。

## 评价与收尾

D648 共同 TTFT/TPOT 合同、物理 allocation-union GPU-s、原生 token 和
`n_correct=null` 的 3B 结构限制均保持。运行失败、资源中止或机制未触发都
保留，不进入完整排名。完成后按既有 D1084 收尾路径：资源释放 → D648 重分析
→ profile/tier/delivery 审计 → 与 D1082 Full W1 的单轮描述性对照 → 白名单备份。

远端只启动已发布 3B gzip 服务；不打包、不重建工件、7B/k3s 不动。测量期间
不安装、构建、清理、压缩、修改远端或启动另一 GPU 任务。临时 NVMe/HOST
目录由 runner 绑定到本轮独占路径；完成后必须为空。

## 完成结果与当前论文含义

D1085 已于 2026-11-06 完成并闭合。4,000/4,000 请求到达终态，成功 4,000、失败
0；launcher、回放和 watchdog 均返回 0，远端服务在证据收集后停止。物理
allocation-union 测量完整，得到 6,072.0008 GPU-s；132 条远程制品传输、请求期
打包 0 次，远端健康与传输日志已复制到本轮 raw 目录。D648 共同合同下，联合
TTFT/TPOT SLO 为 3,946/4,000（98.650%），平均 TTFT 322.021 ms，P95 TTFT
666.525 ms，平均 TPOT 14.787 ms，平均 E2E 1,912.349 ms。

与同一当前实现、同一 W1 trace 的 D1082 Full 对照时，ElasticOnly 的联合 SLO
高 2.025 个百分点，P95 TTFT 低 36.197%，平均 E2E 低 18.044%，但物理 GPU
占用高 12.583%。因此本轮证据是明确的资源—尾延迟 trade-off，而不是 Full 或
ElasticOnly 的统一胜出；不能把 ElasticOnly 的较低延迟归因于 adapter-management
机制，也不能据此宣称全局最优。两者均为单 seed 描述性结果，且 3B 的数值
adapter correctness 为 `n_correct=null`，故 `ranking_eligible=false`，不进入正式
跨系统排名。

机制触发与配置审计也与预期一致：ElasticOnly 有 8 次 scale-up、7 次
scale-down，关闭 readiness routing、scale-up handoff、hierarchical residency、
coordination 和 effective-capacity admission；Full 对应开启 handoff、hierarchical
residency 与 coordination。D1085 的单轮对照产物见
`paper_results/ieee_tc/ablation/d1085_3b_elastic_only_w1/completion/versus_d1082_full_w1.json`。

本结果不改变 D1082、D1083 或历史 D1057 的身份，也不替代后续 ElasticLocality
同版本运行及其余 A1/A2–A5 消融。下一步应在资源门槛满足后继续同版本
ElasticLocality；在此之前不依据本轮 trade-off 人工改写机制或筛选结果。
