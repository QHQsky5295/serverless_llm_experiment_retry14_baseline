## 解释与边界

D535只完成双方共同的通用sampling软件构建，不代表所有模型相关JIT已预热。
D536实际生成新的torch.compile前缀6d1961d6a9；worker0记录graph compile
9.01s、总compile31.58s、engine初始化56.71s，并有首次LoRA Triton JIT提示。
这些真实开销全部计入原始测量，不事后扣除，也不把全部未达标都归因于启动。

预运行清单封存的是既有模型前缀及D535通用sampling；不能用它证明新模型
前缀在运行前已封存。下一步只做有界的既有日志/配置/缓存身份核查，明确
D533是否会继承D536新产生的模型编译准备。未完成该核查前，W1 U_ref/Q_ref
仍未冻结，D533尚未启动；不自动否定D536，不重跑它来挑选更好结果。

分析复用现有resident_rr_v1/full4000_w1入口，D531的103项输入检查与D534的
16项编译入口检查按SHA链复用，不重新执行资格流程。正式指标仍为冻结V1加
单轮V2；无CI、显著性或跨场景最优结论。不与不同工作负载的W0直接排序。
