## 解释与边界

本结果解决了 D524 原生整数表示不兼容导致的失败，并取得与候选执行身份
匹配的新时间 profile。覆盖检查没有缺类，也没有用旧时延或缺省值补齐。
58 项受影响的离线校验测试全部通过，包括新测量与旧输入目录隔离、源文件、
执行 commit 和篡改拒绝测试。所有本地资源域已递归检查为空并关闭，GPU
实际释放，远端两服务及监控均已停止。旧投稿文件保护检查通过。

测量占用 2,112.197101198137 GPU-s；这是初始化工作量，不能充当 Full 的
生命周期资源结果。元数据局部算术与原生身份/数量证据不等于独立完整模型
数值正确性证明，`n_correct` 仍未知。本轮不证明端到端加速或 G1/G2 最优性。
