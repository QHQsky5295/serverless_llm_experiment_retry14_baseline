## 失败与安全记录

首个 vLLM 检查误将已绑定子进程环境送入父进程环境构造入口，严格继承检查
按设计拒绝。真实启动边界是未绑定父进程创建绑定子进程；随后只以该边界
执行此前失败的一项检查，使用原有入口和同一已编译产物，没有改生产逻辑。
它成功后，离线回执脚本因将字符串传给要求 Path 的 digest 接口而报错。
仅用独立离线封存补齐回执，未重复已成功构建、加载或测试。
原失败源文件、日志、返回码和全部成功记录均保留，不能把原失败改成通过。

实际构建资源域峰值3,511,922,688字节，memory.high事件39,172次；max、
OOM、OOMkill和swap均0。节流是这次受限软件构建的真实条件，构建时长不是
推理性能。加载验证峰值1,535,655,936字节、内存事件/swap均0。
每个资源域均核对真实递归进程为空、精确身份关闭及路径消失。
