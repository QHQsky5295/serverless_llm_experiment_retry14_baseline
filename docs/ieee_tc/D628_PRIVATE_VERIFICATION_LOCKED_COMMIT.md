# D628：私有内容核验与全局发布事务分离

2026-10-17，CPU资格前登记，父版本6625a7e。不是已接受的性能优化。

依据：D626封存W2准备分解及D627实际32MiB组件。D627六次调用全部SHA
update在owner锁内，占81.556–90.323ms；锁持有89.783–216.844ms。
没有在线等待测量，不能相减预测W2收益。D595并行压力方案已退化并回退，
D606/D610库存遍历改进已保留；本改动不重复上述方案，不降低确认频率。

假设：已预留、不可被协作式mutation删除的私有workspace可以完成完整内容
SHA而不独占全局owner；这样其他来源读取/规划仍能进行。最终重新检查
transfer/workspace/expected身份、真实容量、来源/cancel以及私有文件签名，
再在同一owner锁内rename+确认。检验失败仍抛错，无弱校验或备用路径。

远端与受管本地copy走同一分层；copy的原始source lease保持到同步任务结束，
source身份/cancel检查移入最终锁内回调，不保留外层锁抵消改动。legacy
unconfirmed和同步legacy copy保留原受锁语义。SHA字节、精度、预算与九公式
不变，没有增加线程/并发配置、场景分支或陈旧库存。生命周期外部任意写者
仍不是cooperative owner协议能排除的行为；提交前后签名观察继续检测。
