平均E2E五段为：提交滞后0.002895 s、提交后至dispatch16.601959 s、
service TTFT12.088131 s、decode5.942911 s、完成通知0.005773 s。
service TTFT仍包含原生后端排队，不将整个阶段误称为prefill计算。

1. 前500请求平均TTFT207.030 s，其中router queue132.747 s；第二段
   平均TTFT16.697 s，router queue已约0.018 ms。第1000条后的六段
   平均TTFT为1.069、0.912、0.548、1.234、0.413、1.640 s。数据支持
   初始注册/准备等待及其积压是长尾的重要来源，不能把全程延迟均称网络时间。
2. 八个固定500请求区间的平均TPOT为52.061–53.227 ms，均超过共同3B
   长度分组阈值29.922/36.216 ms。0联合达成并非仅由初始等待造成；不按
   本系统自身的慢warm结果放宽共同阈值。区间只是事后描述切片，不替代主结果。
3. 同配置W0的平均/P95 TTFT为38.253/323.387 s；本轮W2分别较低24.99%/
   27.27%，但TTFT达成率从76.175%降到75.125%（下降1.050个百分点）。
   因而不能预设更快轮换必然恶化每个时延统计，也不能用尾部改善掩盖达成率
   下降。单轮对照包含不同adapter–shard请求分布，不据此单独证明某项机制
   收益或统计显著性；总U差异约0.16%也不作稳定资源优势主张。
4. 该工作点没有满足G1/G2共同服务条件。保留未达标行、阶段解释和全部
   数据；不从一个静态分片工作点断言Loquetier所有部署均不可行。必要模型
   适配和现有矩阵已完成，不因排名或低SLO追加配置搜索。
