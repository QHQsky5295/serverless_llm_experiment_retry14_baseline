## 问题与控制条件

D128 将冻结快照上的纯规划计算移至服务资源域内的一个 CPU 进程。
组件测试支持请求事件循环响应改善，但增加了总计算/通信时间，不能代替
完整负载验证。本轮检查其是否足以改善普通 Full 的排队与资源结果。

- Runtime：`75deef6873c6e0a3cdbf604498fe0464e6f46bd5`，已推送备份。
- 原 7B W0、4,000 请求、500 个可访问逻辑 adapter、同一 D89 profile。
- 与 D125 配置仅三个本轮输出/缓存路径不同；同 cap2/slots4/cpu24/.70。
- `fixed_length_greedy_v1`，同计划到达时间及 1,800 秒资格保护；无详细 CPU profiler。
- 真实远端已发布只读交付缓存不变，不重新打包、生成权重或负载。
- 开发诊断身份；无正式 SLO 阈值、无数值 adapter 可区分性合格结论。
