## 三个独立维度

1. 发表资格：可核验的正式论文、venue/year、官方代码来源。
2. 实现范围：论文核心机制→实际路径→运行事件/微测→未触发项。允许机器、
   接口、模型注册、安全和必要正确性适配；不要求原论文全部硬件/细节一致。
3. 可比性：相同输入/生成、原生绑定、时钟和真实资源计量，保留数值证明未知、
   异常差结果及其适配审计。发表资格不自动升级为正确或完整复现资格。

HydraServe D510 的4000请求及34个原生worker已完成；该运行全部pp1，不能
据此宣称验证了 pipeline consolidation。既有独立局部算术微测也不等于完整
流水线效果。允许作为明确范围的适配实现观测，结论不得否定未触发的机制。
Loquetier D445采用原生SMLM与四个静态分片；注册前长队列不能无证据地归为
原论文机制缺陷。异常若有适配错误证据，仍按必要修复规则处理。
所有系统的本机机制证据和局限应随主表一起引用，不以一个“已发表”布尔值代替。
