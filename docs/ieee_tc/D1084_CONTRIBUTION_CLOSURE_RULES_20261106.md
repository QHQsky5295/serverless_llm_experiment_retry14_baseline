# 贡献导向的实验收尾：不以无界优化代替证据闭环

用户进一步明确：本规范适用于全部实验的收尾审查，不仅适用于消融。
本补充不改PLAN范围、冻结指标、阈值、配置或本轮W2，只明确推进和写作判断。
W2测量期间完成的是原始文献只读核查，不开展本机重型分析或新优化。

## 1. 同类论文怎样让实验服务于贡献

- HydraServe §8.2/Fig.8逐步加入启动优化，用冷启动时延检查累积效果；
  §8.3另报SLO以及TPOT/资源取舍，不要求每个指标都同时改善。
  [官方论文](https://www.usenix.org/system/files/nsdi26-lou.pdf)
- dLoRA §7.3以单GPU隔离动态batching，避免与跨副本迁移混杂；§7.4以
  排队时延检验负载均衡；§7.5另报控制开销。不同贡献使用相应机制证据。
  [官方论文](https://www.usenix.org/system/files/osdi24-wu-bingyang.pdf)
- ServerlessLLM §7.3保留相同位置选择来比较preemption/live migration，
  并报告无迁移时接近、资源受限时收益受限等情形。
  [官方论文](https://www.usenix.org/system/files/osdi24-fu.pdf)

以上是这些论文实际采用的证据组织，不是顶会统一准入标准，也不是它们
内部开发停止规则的公开证明。由此作本项目的执行判断：终止某个实验应
依据该问题已得到完整、可解释的观测，而不是追求所有消融指标大幅下降。
同类论文中的特定倍数不移植为PrimeLoRA必须达到的阈值。

## 2. 四种状态分开

1. **运行收尾**：唯一完整执行、实际资源释放、输入/计时/资源核算完成即封存，
   包括有效负结果；不因胜负重跑同键。
2. **机制解释收尾**：机制触发证据、目标差异和相关阶段结果足以解释效果；
   未触发可作为不适用边界，不称机制有效，也不为凑结果无限增加运行。
3. **论文主张支持**：按既定G1/G2和单轮证据，明确支持、取舍、未支持。
   运行结束不等于支持了主张；未支持也不阻止完成其他已批准机制实验。
4. **整体目标完成**：完整矩阵与交付完成且结论经证据核对，不由局部95%达标
   或某个消融的正值替代。不得把本补充当成取消剩余实验的许可。

## 3. 不额外发明“提升至少X%”门槛

G1继续用共同联合SLO≥95%下物理GPU时间，G2继续用共同75%预算/SLO下
W1/W2 P95 TTFT及联合率差值。强说服力来自有效对照、真实资源收益与
机制证据一致，而非事后选择有利门槛；只微弱领先不宣称稳健或显著。

用于解释量级的简化模型（分析假设，不修改论文九公式/在线策略）：

- 对同一请求分布且无排队反馈的直接路径，若比例f的请求减少准备时间δ、
  每请求平均新增控制开销o，则平均直接收益近似f·δ−o。需用实际触发比例
  和阶段数据估计，不从想要的提升反求参数。它不预测P95，也不含排队放大。
- handoff在固定任务、无新增竞争且唯一收益来自重叠时，准备d与可用重叠
  窗口w的直接节省上限为min(d,w)。未使用准备、竞争和错误目标会减小净值。
  完整系统可能因排队反馈产生不同变化，不能把该上限当完整E2E下界。
- confirmed-state需先看到状态分歧和实际错误/更好位置选择，再检查相应
  请求阶段；shadow不给反事实TTFT。没有相关分歧就不能归因于状态传播。
- admission必须同时保留推迟加载的后续代价；只展示decode局部改善不足。
- GPU收益直接为sum_d integral(a_ablation,d−a_full,d)dt；不能把累计请求
  延迟差或planner CPU时间差等同于GPU释放收益。生命周期/扩缩容证据必须吻合。

这些解释能识别“收益为何应当有限或值得期待”，不能保证每机制固定百分比。
少量cold/first-service改善可能在全体P95不显现；应同时保留预定义机制
样本与完整负载指标，不改分母、不将事后挑选子集充作主结果。

## 4. 有界推进规则

- 当前先完成同版本D1084 W2，随后做受共享实现影响的A1，先检验已知的
  ElasticOnly/ElasticLocality反例。不能在W0/W2之间重新调参或重启baseline。
- 正确定义的消融保留全部非目标机制与资源配置。只有实际泄漏了应移除的
  贡献、或存在真实实现错误才修正；不添加sleep、缩资源、关闭合法公共缓存、
  改SLO或隐藏更好结果。D1083既有语义审计未发现这样的泄漏。
- 每个新优化仍须已有日志/失败历史+原始论文/源码+一个可证伪假设；沿用
  PLAN的每假设最多两轮最小验证，不另加短回放或重新资格。无新证据则
  结束该候选、记录边界、推进下一项已批准实验，不无限微调同一方向。
- 已经支持G1资源观测的版本不因单个平均TPOT上升就重新否决；G2尾延迟
  未支持则明确保留未完成状态。两种目标不混成“所有指标第一”的新总分。
- 需要收窄核心论文主张或扩大实验授权时向用户说明具体证据，不擅自改论文。
  现阶段不修改LaTeX/PDF，所有历史/负结果和已批准实验仍保留。

本次只有三个原始论文的有限核查和执行解释，不启动新的文献综述支线。

## 5. 全部实验的收尾与推进标准

以下是既有计划的完成判据索引，不新增性能矩阵、安全门槛或审计关卡。
逐项优先复用现成证据；同一核查通过后不重复执行，没有具体缺陷不重跑。

| 实验类别 | 何时结束该项工作并推进 | 不足时如何处理 |
|---|---|---|
| P0来源/指标修正 | 主表与Full来源映射清楚，统计错误离线修复且来源保存 | 只有执行错误或无法恢复的关键计量才重跑受影响键，不重跑全矩阵 |
| P1/P2实现和后端资格 | 核心公式对应、实际使用路径及必要正确性/计量验证完成 | 有具体缺陷才修；结构池数值限制按已批准范围披露，不重开资产生成 |
| 外部baseline复现 | 必要适配、实际机制范围、完整冻结运行和异常表现解释完成 | 偏离原机制/输入/计量的真实问题修复；低SLO或不如原论文不自动触发无界调参 |
| M1/G1 | 同版本规定场景完整核算，共同SLO可行性和GPU资源顺序明确 | 无优势则保留结果，仅凭具体新瓶颈开启有界候选；不只反复和旧自己比较 |
| M2/G2 | 预算/SLO约束、P95和联合率差已核算，已测工作点可比范围明确 | 未测对手其他预算配置不称全域不可行；未支持尾延迟优势不写成已支持 |
| A1–A5/S1–S3机制 | 已批准对照与直接机制证据完整，能解释增益、代价或未触发 | 修复真实定义错误；无法支持时限定该机制主张，不人为削弱对照、不按结果凑样本 |
| S4–S13敏感性 | 预定点已完成或有具体不可行记录，变化趋势、边界和失败保留 | 不要求全部点第一；只有新缺陷才补受影响点，不不断向有利方向扩展扫描 |
| CE/价格/阈值/Pareto离线分析 | 全部既定切片、公式/单位/来源核对完毕 | 保留排名翻转，不为使CE更好重跑；评价变化不冒充在线系统改进 |
| 图表/审稿文档/发布 | 同版本canonical数据、完整限制、来源和备份可查 | 修正表达与引用，不用重跑替代排版或文档修复；图表仍遵守当前延期要求 |

每项结束记录只需：原科学问题、实际证据、支持/取舍/不支持、下一主线。
这不是额外报告工程；直接复用已有结果表和执行状态。完整计划范围不省略，
但一个负结果不允许把整个主线锁在同一局部优化上。

当前应用：D1083 W0已收尾，尽管P95退化仍永久保留；D1084 W2完成后按
同样标准封存并形成当前版本三场景观察，再进入受影响A1。外部baseline
已有矩阵不重开；尚未做的G2机制解释/受控实验/敏感性不能被“已95%达标”
代替。整体目标是否达到继续由最终真实结果决定。
