## 3. 当前解释与不得越过的结论

1. 本轮观察到完整原生生成，D135 的那一个失败在本轮没有重复出现。这不证明
   FIFO 修正解释了全部性能问题，也不是单次运行的统计因果结论。
2. 最终统计确认排队仍明显，不能只因零失败接受候选为性能优化成功，
   更不能把原生vLLM时间替代用户端TTFT。D136的FIFO正确性反例已修正，
   但当前Full并未证明吞吐/资源目标改善。
3. 数值 adapter 身份与共同 warm SLO 仍未合格；物理记录明确
   `n_correct=null`、`eligible_correctness=false`，不以 4,000 作已合格分母。
4. 3B 性能仍为 OPEN，遵循 `LEGACY_CURRENT_PERFORMANCE_GATE_20261001.md`。
   D137 完整收尾后返回新旧差距与最新候选 3B 验证，不提前恢复完整基线阶段。
