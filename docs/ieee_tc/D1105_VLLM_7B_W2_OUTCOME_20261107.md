# D1105: vLLM 7B W2 qualification outcome (2026-11-07)

## Status

`D1105` is a failed qualification attempt and is not a performance result.
The run did not start vLLM or replay any requests.  It failed while staging
the selected W2 adapters from the qualified remote artifact service.

## Identity retained for audit

- system: vLLM 0.10.2, TP=1, DP=4, `static_remote`
- model: Llama-2-7B (`llama2_7b_main_v2_publicmix`)
- workload: `llama2_7b_auto500_formal4000_s8`, 4,000 requests, 500 adapters
- trace and subset: exactly the D1103 ServerlessLLM W2 inputs
- frozen content manifest: 7B `artifact_content_v1`, client SHA
  `684c7ab113b6a51b694066753b340fce4eb0b26f565e1f9b7ebbd97d3b8ea050`
- result namespace: `18_vllm_w2_v2/d1105_20261107_vllm_w2`

## Failure diagnosis

The content-manifest correction was active and was accepted by the remote
service.  A one-adapter probe had already passed.  In D1105 the launcher
started the remote service and immediately launched the staging process without
waiting for the HTTP health endpoint to become ready.  The first submitted
adapter request received `Connection refused`.  The thread pool then continued
the remaining tasks while the main process surfaced that first failed future;
the resulting partial cache is not a completed staging result.

The remote journal shows successful prepublished responses for the later
adapter IDs and no vLLM process was created.  This is a launch-readiness race,
not an artifact-content mismatch and not an inference-performance observation.

## Corrective action

The next execution key must keep the same trace, subset, manifest, engine
arguments, and resource envelope, but must wait for an authenticated `/health`
response before invoking the staging helper.  This is an external service
readiness condition; it does not change request semantics or baseline policy.
The staging helper still performs strict file-level content verification for
every adapter.

The partial cache is rebuildable staging state, not a unique result or source
artifact.  It may be reclaimed only after this record and the service journal
evidence have been preserved, so that the next full staging run remains above
the inference-node disk reserve.
