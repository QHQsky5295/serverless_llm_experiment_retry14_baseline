不同结论，不能相互替代。

## 3. G1资源优势与G2尚不能宣称的内容

相对vLLM，PrimeLoRA W0/W1/W2的U分别减少50.5724%、31.3518%、49.2115%；
联合达成率分别低2.125、4.100、4.175个百分点。P95 TTFT分别为vLLM的
4.3653、6.2942、3.7867倍，不能隐藏原始时延取舍。

相对ServerlessLLM：W0资源减少50.4848%，联合达标增加0.125pp，但P95
TTFT更高80.1507%；W1资源减少31.1543%，P95 TTFT降低93.4412%，联合
达标增加15.825pp；W2资源减少49.1277%，联合达标低2.300pp，P95 TTFT
为其3.4788倍。W1的ServerlessLLM未过95%，该项资源差只能作为原始观测，
不能称为两个共同达标点之间的资源比较。

W1/W2的75%预算分别为6754.783565160236与12083.063870235463 GPU-s。
PrimeLoRA实际消费为预算的91.5309%与67.7179%，同时满足95%时延要求。
两个场景当前只有PrimeLoRA同时满足这些观测约束。但vLLM/ServerlessLLM
已有点超预算，不等于它们所有可能配置都不可行；不能把它们删掉后宣称
已经证明“相同预算尾延迟支配所有系统”。联合达成率并非对所有基线不低于，
不能写成服务质量全方位领先。正式正确性资格与实际同预算比较边界均保留。

## 4. 已有观测点的阈值与预算切片

复用D810的离线分类，未改变在线配置或共同评价毫秒值。

- 90%/95%时：W0/W2资源顺序为PrimeLoRA、ServerlessLLM、vLLM；W1为
  PrimeLoRA、vLLM。其余系统和失败记录仍显示，不进入达标资源排序。
- 99%时：三个场景仅vLLM通过；不能外推PrimeLoRA在更严格服务要求下领先。
- 50%预算且95%达标时：W0仅PrimeLoRA，W1/W2无观测可行点。
- 75%预算且95%达标时：三个场景仅PrimeLoRA；W0预算仅作补充诊断，G2
  仍限定W1/W2。100%预算时保留各场景全部达标点。
- 这是固定工作点资格切片，不是各预算下重新优化过的Pareto前沿；其他
  TTFT/TPOT倍率、带宽、规模等敏感性仍未因此完成。
