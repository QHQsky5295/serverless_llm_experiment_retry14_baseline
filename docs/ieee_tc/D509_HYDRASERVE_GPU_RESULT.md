这是 D508 必要适配后的实测资格，不是完整 W0 主比较。输入、原生后端和
调度保持冻结；未增加请求期限、修改共同 SLO 或扫描 baseline 性能参数。

| 观测项 | 实测结果 |
|---|---:|

| 实际逻辑 adapter／远端获取 | 29／29 |

| high／max／OOM／OOM-kill／swap | 全部 0 |

1. 逐请求 prompt、adapter/index/path、原生 token 数、可靠时钟、实际 worker
   身份、远端内容和传输关联均通过独立核验；没有请求中打包或本地回退。
2. D507 超时前每个 worker 的不同 adapter 重叠峰值为 1；本轮实际出现 8。
   结合固定官方源码中的容量限制，这支持必要容量适配确实解除此前的串行
   限制。不据此声称吞吐提高八倍，也不把短前缀外推为完整负载优势。
3. 原生两实例自然回收。物理 GPU 区间并集独立积分一致；四个互斥窗口为
   0、310.338267、25.070556、93.801865 GPU-s。所有实际 GPU 上下文、服务域
   和所属远端服务退出，端口关闭。不是用逻辑副本归零替代真实释放。
4. 两个原生 GPU worker 各报告 814 GPU KV blocks、512 CPU blocks；使用中
   GPU 显存峰值分别 21,708,472,320 与 21,467,299,840 B，未越界。原生快速
   启动预算逻辑保留。源文件与实际批接纳值证明 pp1 的配置容量为 8；并发
   观测是实际执行证据，不声称独立逐槽探针或多阶段 consolidation 已验证。
