# D1089：3B NoHOST W1 当前实现重测登记

## 科学问题

D1063 定义了 NoHOST 单因素边界：关闭独立 HOST 最终驻留与复用，但保留 GPU
backing、NVMe/Remote 回退、请求期 staging、owner finalization 与 release
安全语义。本轮用当前生产实现、同一 W1 轨迹和同一 D648 共同 SLO，测量取消
独立 HOST reuse 对物理 GPU-s、尾延迟和联合 TTFT/TPOT SLO 的影响。该实验不把
“没有 HOST reuse”误写成“没有 host memory”，也不改变 adapter、prompt、arrival
或生成契约。

## 单因素不变量

仅采用配置中的 `storage.preloading.independent_host_reuse: false` 和
`scenarios[tc_ieee_full].preloading.independent_host_reuse: false`。保留 Full 的
confirmed routing、arrival-prefetch、handoff、hierarchical residency、coordination、
admission、GPU/NVMe/Remote backing、native host workspace 以及释放审计。不得把
host descriptor、native workspace 或 request staging 的存在解释为独立 HOST cache
reuse；也不得把 NoHOST 的资源结果归因于关闭其它机制。

## 有效性和分析门槛

只有 4,000 请求终态完整、服务/replay/watchdog 返回 0、物理 allocation-union
闭合、132 条远端传输全部绑定健康 clock 且为有效交付、profile/tier 绑定通过、
NoHOST feature gate 与机制审计一致时，D1089 才进入 D648 离线核算。报告联合
TTFT/TPOT SLO、P95 TTFT、平均 TTFT/TPOT/E2E、物理 GPU-s/request、GPU/NVMe/
Remote/host staging 计数、scale-up/down 和 handoff/preparation/residency/admission
触发计数。`n_correct`、`ranking_eligible` 必须原样保留；若为 null/false，本轮只
作时延、SLO、资源与机制诊断，不进入正式跨系统数值正确性排名。

## 预注册比较

闭合后与同当前实现的 D1082 Full W1 做单轮描述性比较，主资源指标使用物理
allocation-union GPU-s/request，旧 `infra_gpu_seconds_total` 只作辅助审计。差异
若显示资源—尾延迟 trade-off 或未分辨，按事实报告，不筛选运行、不改生成契约、
不把 NoHOST 结果包装成普遍最优性结论。
