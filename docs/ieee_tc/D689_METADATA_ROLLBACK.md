## 为什么撤回

D687实时HOST清点描述物化在组件微测中平均快13.1%，但唯一完整D688 W0
联合3645/4000（91.125%），低于直接参照D682的3694（92.350%）；
U15897.107082没有减少。完整结果及与D682/D677/D672的比较已推送
`16a5f6943110dfef33eb1c35e2e6b672a9ef50c8`，不删除退化或重跑同键找赢家。
这不足以证明该改动因果导致全部退化，但也没有接受它为系统性能改进的证据。
