queue=0、active=0、TTFT样本1条，其P95=7503.912ms，高于原控制上阈5000ms。
三个决策均由该首期TTFT驱动。这里的控制上阈不是共同评价SLO。

第一个1000请求窗口平均持卡3.9654张，其余三个窗口完整保持4张；后三区间
GPU-s与D677相同。到达窗口1894个控制样本中，TTFT低条件一次也未成立，
原生记录中没有缩容。在线P95最小927.907ms，仍高于既有219.518ms低阈。

核对当前`_exec_request_in_reservation`与`_ieee_protect_selected_source`：
名为`runtime_slot_wait_ms`的245.914ms全体均值，不是单纯“槽位耗尽排队”。

248.432/266.827/208.551/132.369ms；不能只优化router排序就预言全部消失。
