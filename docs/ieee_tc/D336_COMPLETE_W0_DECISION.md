# D336：容量工作点减少持卡时间，但尚未消除服务质量取舍

2026-10-08；7B 原4000请求 W0 开发回放及完整核验完成，不是正式验收。
不重复同配置寻找胜出，不重建工件/负载，不绘图，不覆盖任何旧结果。

## 结论与比较边界

D336 的物理 GPU 占用比 D335 低12.28%，也低于更早的 D332；因此不是
仅在上一慢候选上获得资源改善。但平均/P95/P99 TTFT、TPOT 和平均 E2E
均未同时改善。**保留为有真实资源节省、服务质量有代价的开发工作点，
不接受为已达成 G1/G2 或全面优于旧 Prime 的结论。**

原生输出数量、身份/内容/slot 绑定与时间恒等式通过，不等于独立数值
资格。N_correct 仍未知；共同 warm、Resident 与匹配旧/新 Prime 的正式
资格仍开放。暂定 timing 数值高于95%不能据此填成正式 SLO 合格。
每配置仅一次开发运行，不出 CI、不作显著性或因果优越性主张。

## 资源下降有真实释放证据，不来自折扣或提前结束

沿用逐卡 allocation/release 区间并集：
`U = 首次持有至最后释放的 envelope − 中间实际释放间隔`。

| 物理资源分解 (GPU-s) | D332 | D335 | D336 |
|---|---:|---:|---:|
| envelope | 15840.039268 | 15845.145223 | 15847.771133 |
| 中间释放间隔 | 457.551054 | 97.092069 | 2033.436636 |
| U | 15382.488214 | 15748.053154 | 13814.334497 |

D336−D335 为 `−1933.718657 = +2.625910 −1936.344567` GPU-s，主要
来自中间真实释放间隔增长，而不是删去低负载、缩短回放、利用率折扣或
收尾漏计。七个释放间隔中，最长1550.334692→2695.884796秒，持续
1145.550104秒；其后重新分配的成本同样计入。该恒等式不是反事实估计。

1890次控制观察中，扩容10次、缩容7次；D335为4/1，D332为9/6。
队列低1703次、active低1765次、两者低1604次，all-low598次；仅延迟
条件阻止 all-low1006次。没有删去或提高延迟保护。动作更多并不自动是
收益或缺陷，需与完整 U/服务质量一起解释。

互斥时间窗 GPU-s：到达前37.054542、到达窗口13730.122308、drain
9.185336、终态后释放37.972310；总和与 U 一致。

## 延迟变化目前能解释到哪里

| 平均 admission 分项 (ms) | D335 | D336 |
|---|---:|---:|
| 计划到达到接收 | 228.491 | 209.523 |
| dispatch 窗口等待 | 31.098 | 72.329 |
| runtime 选择/保护包络 | 347.121 | 327.394 |
| admission 合计 | 606.710 | 609.246 |

前三项可加，恒等式误差零。routing67.753ms已含于 runtime 包络，不能
再次相加，也不能把327.394ms全称为计算容量不足的排队。队列窗口等待
增加抵消了其他分项的下降；service TTFT 均值595.780→601.599ms。

2012个最终 GPU 来源请求触发既有合并 native 操作，HOST/NVMe/Remote
分别1035/817/136；触发本身不证明该实现节省延迟。比 D335 有207条
输出 token SHA 变化，完整保存，不以名字/slot正确替代数值资格。

TPOT退化可能与较少副本上的并发密度、加载/准备重叠或执行路径开销有关，
但当前汇总不足以区分。下一步优先利用本轮与历史已有请求/生命周期日志
定位这部分，结合历史失败尝试和原始实现资料提出一个可证伪假设。
不继续提高软目标、删除 TTFT 条件、人为钳制两卡或放宽 SLO。
