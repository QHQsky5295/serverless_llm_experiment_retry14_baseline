- 完整请求身份、原生 token 数量、原生 adapter index/path、输入哈希、时间线、
  实际 worker 生命周期及远端 transfer 关联核查通过。

  `[578, 2326, 1288]`，与 D803 的独立参考一致；4000 条全零序列为 0。

  以及全量独立数值正确性未知的原始身份保留，不改写为证明通过。

  原生 CPU provider、私有共享内存和实际 worker 交付路径执行；D805 已发现
  的短尾接收错误经 D806 验证修复，此轮没有重现全零输出。
