prefill增加0.253733ms；合计为TTFT增加49.489938ms。主要增量发生在推理前。

wait减少15.201004ms，但runtime slot wait增加33.441221ms、routing观测耗时

端到端收益；必须核对仍被串行化的工作量和线程交接，而不是继续扩大异步包装。
