机器可读文件保存未舍入数值。这里的“原生合同”指已有完整请求、adapter
绑定、内容、token 数量、计时和物理生命周期证据，不等于全量独立数值正确性。
原始 `n_correct=null`、独立数值证明未知、formal/complete 资格 false 均不改写。
因此这次冻结的是已知开发负载的**数值资源参考**，不宣布正式正确性或 G1/G2 完成。

1. 各场景都重验四个实际设备的闭合区间并集，四段互斥时间窗之和等于总量；
   4000 个终态、原生绑定和实际释放齐全。未用逻辑副本时间替代物理 GPU 时间。
2. 每场景只采用事先登记的一个完整运行，没有重复择优、均值、置信区间或
   从短回放外推。W1 的到达窗口较短，不能把其较低总 GPU-s 当作优化收益。
3. 三场景共享 vLLM 0.30.0、四卡 DP4/TP1、8-lane、相同生成合同、CPU/内存
   包络及部署通知提前60秒。实际 JIT 和释放尾部计入；底层全部编译缓存初态
   等价性没有得到证明，不能据此作单机制因果归因。
4. W0/W1 实际出现132个逻辑 adapter，W2 为497；既有500-ID池仅有两种独立
   权重 SHA 的限制保留。W2 不用不同 adapter 的 W0 输出来证明正确性。
5. 真实远端请求中打包为零；各次实际传输、竞争、本地物化保留。全局历史
   `remote_qualified=false` 与当前路径 `remote_affected_path_qualified=true`
   分开记录，不以本次分析覆盖旧标记。
