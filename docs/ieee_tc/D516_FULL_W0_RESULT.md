- GPU准备1785个计划、2233次attempt、2230条原生回执：1902次acquired、
  328次deferred，另有2次superseded、1次observing。改动路径确实触发；
  缺少最终回执的attempt不补造成功或失败。
- HOST准备1242次，其中residency 1106、handoff 136。dispatch前状态为
  GPU 2437、HOST 574、NVMe 855、remote 134；不将下载后状态当事先命中。
- initial activation 1、natural scale-out 22；23个CPU准备进程全部实际激活，
  19次同卡后续replacement在前一持有者真实release之后开始。没有把CPU-only
  准备冒算为GPU持有，也没有将准备许可等同于engine-ready/first-service。
- 132次远端传输，131480060线上字节；全部与服务端传输记录匹配，请求中
  打包为0。通用请求归属摘要有131次匹配、1次无请求归属；严格完整transfer
  ID核查132/132通过，无请求归属不被补写成某个请求的延迟。
- 与D476同后端4000条输入完全匹配；3811条输出序列摘要相同，189条变化，

  batching；原始N_correct保持null，独立数值正确性没有因此升级为已证明。
