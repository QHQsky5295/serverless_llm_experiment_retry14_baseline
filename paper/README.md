# PrimeLoRA Paper Draft Workspace

This directory stores the current PrimeLoRA manuscript draft used by Codex when
reviewing paper text, figure insertion points, and evaluation-result wording.

## Files

- `primelora_current_draft.tex`: current manuscript text provided by the user.

## Workflow

1. When the manuscript changes, update `primelora_current_draft.tex` first.
2. Update `docs/PAPER_LATEX_INSERTIONS.md` with the exact paragraph-level
   replacements or insertion snippets.
3. Keep generated figures and table inputs under `figs/paper/`.

This keeps the paper review loop grounded in repository files rather than chat
history.
