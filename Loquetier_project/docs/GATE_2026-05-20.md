# Loquetier Gate Notes 2026-05-20

Initial adaptation gates are in progress.  The first accepted boundary is:

- isolate Loquetier in `loquetier_20260520`;
- compile upstream SMLM kernels for RTX 3090 (`sm_86`);
- add local build support for Llama-3.2 3B's GQA group size 3;
- add PEFT/Transformers compatibility shims only where upstream APIs moved;
- run real Llama-3.2 3B and Llama-2 7B adapter smoke tests before any formal run.

This does not change Loquetier's virtualized multi-LoRA forward path or replace
its scheduler with PrimeLoRA/FaaSLoRA logic.
